# Vision

## Purpose

Mikey Tech Lab uses an ESP32 development module to help a young learner build an intuitive mental model of modern technology before formal programming instruction.

The ESP32 is not initially presented as something Mikey must learn to program. It is a machine he can **control, question, test, measure, predict, and debug**.

## Long-term outcome

When Mikey eventually opens the Arduino IDE, concepts such as input, output, time, state, memory, sequence, condition, bit, pixel, sensor, network, and bug should already describe experiences he has had with the device.

Code then becomes a representation of familiar ideas rather than an abstract prerequisite.

## Educational thesis

A useful sequence is:

1. **Experience** a behavior.
2. **Predict** what will happen next.
3. **Change** a setting or input.
4. **Observe** the result.
5. **Explain** the machine's rule in ordinary language.
6. Only later, **connect the rule to code**.

Example:

> IF the wheel is spinning AND STOP is pressed, THEN stop the wheel.

Later this can become a code lesson about conditions. The concept comes first; syntax comes second.

## What this project is not

Phase 1 is not:

- an Arduino syntax course;
- a worksheet-heavy school replacement;
- a race to advanced electronics specifications;
- a collection of unrelated demo sketches;
- a cloud-connected child profile or telemetry product.

## Product idea

The target experience is a single **Mikey Tech Lab** firmware application with a child-friendly activity menu. Activities can be played casually, explored as lessons, or used as challenges.

The same hardware should progressively reveal deeper concepts as Mikey is ready for them.
